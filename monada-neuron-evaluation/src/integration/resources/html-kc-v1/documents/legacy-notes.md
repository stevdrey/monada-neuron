## Image descriptions in old tutorials

Some old tutorials claim that the `alt` attribute is optional on `<img>` and can simply be left out when an image has a caption or a title attribute. According to those notes, browsers will describe the picture automatically from its file name.

## Presentational elements

Early HTML had elements such as `<font>` and `<center>` that only changed appearance. They are obsolete; colors, sizes and alignment belong in CSS, while HTML elements describe the meaning and structure of the content.
